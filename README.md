# Athar

An open-source project for exploring Tunisian startups through traceable source data.
Source: <https://github.com/OussemaJaouadi/Athar>.

The first implementation, a terminal workspace for collecting the Startup Tunisia registry,
was retired in November 2026. The application and the data worker that replace it are not
available yet. The design documents remain:
